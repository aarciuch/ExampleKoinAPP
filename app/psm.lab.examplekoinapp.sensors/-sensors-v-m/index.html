SensorsVM

class SensorsVM(sensorManager: SensorManager) : ViewModel

ViewModel responsible for managing real‑time hardware sensor data and exposing it as observable state to the Jetpack Compose UI.

The ViewModel registers listeners for all available sensors (light, accelerometer, proximity and rotation vector) and updates corresponding StateFlow objects. Each sensor has a dedicated availability flag to allow the UI to gracefully handle devices lacking specific hardware components.

Sensor listeners are registered and unregistered explicitly through startListening and stopListening, allowing lifecycle-aware control from Compose screens.
