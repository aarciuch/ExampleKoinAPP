# 📱 ExampleKoinAPP

A simple Android application built with **Jetpack Compose**, **Koin Dependency Injection**, and **SensorManager**.  
The app demonstrates modular architecture, MVVM, DI, and real‑time sensor visualization.

---

## 🚀 Features

- Jetpack Compose UI
- Koin Dependency Injection
- MVVM architecture
- Real‑time Android sensors:
  - Accelerometer
  - Light sensor
  - Proximity sensor
- Navigation with Compose
- Modular and clean architecture

---

## 🧱 Architecture

- **UI Layer** — Jetpack Compose screens  
- **ViewModel Layer** — state management, sensor logic  
- **DI Layer** — Koin modules  
- **System Layer** — SensorManager integration  


---

## 🛠️ Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Koin**
- **Android Sensors API**
- **Navigation Compose**
- **Dokka (HTML documentation)**
